# Roadmap

The project is a preview. Features and release timing depend on validation and user feedback.

- [x] Independent KMP libraries and public-dependency CI.
- [x] Traditional DSL examples and standalone Android demo sources.
- [x] Chinese/English overview and source integration guide.
- [ ] Complete physical-device UI acceptance on Android.
- [ ] Independent macOS/iOS compilation and device acceptance.
- [ ] Independent HarmonyOS KBA build and device acceptance.
- [ ] Validate a browser UI demo and mini-program integration separately.
- [ ] Verify TurboDisplay replay scenarios.
- [ ] Publish and verify Maven Central packages with external consumer projects.
- [ ] Expand examples based on actual integration feedback.

[Report a need](https://github.com/Nobbyyinchen/KuiklyToolkit/issues/new/choose) with your platform, versions and concrete use case.
