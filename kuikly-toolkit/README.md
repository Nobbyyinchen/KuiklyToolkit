# KuiklyToolkit UI

Reusable components for the traditional Kuikly DSL.

[Run the independent Android demo](../docs/DEMO.md) · [Source integration](../docs/QUICK_START.md) · [Examples and boundaries](../docs/COMPONENTS.md) · [Validation matrix](../docs/COMPATIBILITY.md)

- AdaptiveHeightPager: interpolate viewport height using caller-supplied page heights.
- StableImage: preserve fallback and content image nodes while sources load or fail.
- LazyMountContainer: mount once when content approaches a scrolling viewport.
- PaginatedWaterfall: guarded paging with caller-supplied requests and content.
- DebugConsole / DebugLogStore: bounded, injectable in-app logging.

This module depends on public Kuikly core and does not depend on the serialization module. Maven Central packages have not been published.
